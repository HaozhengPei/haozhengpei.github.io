Clink! Chop! Thud!

Learning Object Sounds from Real-World Interactions

Mengyu Yang, Yiming Chen, Haozheng Pei, Siddhant Agarwal, Arun Balajee Vasudevan, James Hays

Third author · Georgia Institute of Technology

A sound can tell us which objects are interacting. We study how to connect everyday interaction sounds to the objects that produce them.

Read paper ↗ Project ↗ Code & data ↗

Which object made the sound?

When a knife hits a chopping board, the scene contains many objects but only a few participate in the sound. Our sounding-object detection task asks a model to choose the relevant object from candidate regions using the interaction’s video and audio. We also evaluate whether an action produces sound at all.

Learning from the interaction

An automatic hand–object detection and SAM 2 pipeline provides object masks for training. These masks select visual patch features, while a pretrained slot-attention model supplies an object prior. Contrastive-consensus pretraining aligns vision, audio, and language. Fine-tuning then uses background regions from the same scene as hard negative audio–visual pairs.

Results

The sounding-object benchmark evaluates 583 clips from EPIC-KITCHENS and 572 from Ego4D, with manually annotated ground-truth objects. A prediction succeeds when the highest-scoring candidate matches a sounding object.

My contribution

I contributed to the object-mask annotation and feature-processing pipelines, along with comparative evaluation and ablation studies on EPIC-KITCHENS and Ego4D.

Evaluation scope

The task assumes candidate object masks are provided. If the candidate detector misses a sounding object, its ground-truth mask is added to the pool. The reported accuracy therefore measures selection among object candidates, rather than end-to-end object discovery or precise boundary prediction.
